03
MooVision
Computer Vision · YOLO Fine-tuning · Seq-NMS · HPC / SLURM

Automated dairy calf cross-sucking behavior detection system built as UBC MDS Capstone in partnership with the UBC Animal Welfare Program. Fine-tuned YOLO on 1,100 annotated clips across 8 experimental splits (random, time-based, pen-based, period-based) — achieving 0.73 average temporal IoU vs 0.70 baseline, indicating accurate event localisation in a naturalistic low-prevalence detection setting. Engineered the full pipeline from 300GB of raw barn footage to automated evaluation reports: OpenCV clipping, proximity-based baseline, Seq-NMS temporal linking, and a Makefile workflow integrating preprocessing, SLURM-parallelised HPC training, inference, and Quarto report generation. Evaluated on F2 score to prioritise recall — missing a welfare event is costlier than a false alarm.

03
GPT-Powered Web Data Extraction Platform
LLM · Flask · Selenium · Runtime Code Generation · Azure

Built at an internal JLL hackathon following the public release of GPT-3.5. A Flask web platform that lets non-technical analysts extract structured data from any website — no code required. Under the hood: Selenium renders dynamic JS pages, BeautifulSoup parses the loaded HTML, and GPT-3.5 on Azure generates Python extraction code at runtime using exec() — inferring the page structure from user-provided sample values. Eliminated hours of manual data collection per analyst per week.
